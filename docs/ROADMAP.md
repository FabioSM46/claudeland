# Roadmap

## 0.1 — Foundation

- Panel indicator and popup.
- Optional desktop card.
- Claude Code authentication status and login action.
- Five-hour, weekly, and dynamic model-scoped limits.
- Preferences, tests, CI, and extension packaging through `pnpm package`.

## 0.2 — Hardening

- Notifications at configurable remaining-capacity thresholds.
- Persist only non-sensitive historical samples.
- Exponential backoff with jitter and richer offline status.
- Automated nested-Shell smoke tests.

## 0.3 — Distribution

- GNOME Extensions review.
- Distribution package metadata.
- Localization infrastructure and Italian/English catalogs.

## Future frontends

- KDE Plasma plasmoid using the same normalized snapshot schema.
- Waybar JSON output for wlroots compositors.
- Optional D-Bus collector if multiple frontends need one polling process.
